# truenas-backup-oauth

Página de referência do aplicativo OAuth **truenas-backup**, usado exclusivamente para o backup pessoal de um servidor TrueNAS doméstico no Google Drive do próprio autor, por meio do rclone (Cloud Sync do TrueNAS).

O aplicativo não é distribuído, não é oferecido a terceiros e não possui usuários além do próprio autor.
